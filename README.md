# Luxy AI by Afraz Studio — Official Website

A complete promotional website for the **Luxy AI** Android app, developed by Afraz Studio.

## Contents

- `index.html` — Home / Introduction page with hero, promotional video, and features
- `download.html` — Download page with direct APK link
- `privacy.html` — Privacy Policy
- `css/style.css` — Modern dark-theme styling
- `js/main.js` — Interactive behaviors (video player, mobile menu)
- `images/` — App logo in multiple sizes (extracted from the original APK)
- `video/promo.mp4` — Custom promotional video
- `download/Luxy-AI.apk` — The official app package for download

## How to Use

1. Unzip this archive.
2. Open `index.html` in any modern browser to preview locally.
3. To publish with your own domain:
   - Upload the entire folder contents to your web hosting / static site host (Netlify, Vercel, GitHub Pages, Cloudflare Pages, etc.).
   - Point your domain (e.g. luxyai.com or luxy-ai.afrazstudio.com) to the hosting.
4. The download button links to `download/Luxy-AI.apk` — keep the relative path intact.

## Customization

- Replace the contact email in `privacy.html` with your real address.
- Update any placeholder text as needed.
- The logo was extracted directly from the provided APK.
